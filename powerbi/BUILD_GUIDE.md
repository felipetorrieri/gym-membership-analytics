# Power BI Build Guide

## Model
Use four core tables: `members`, `monthly_membership`, `visits`, `unit_capacity`, plus a dedicated Date dimension.

## Page 1 — Executive Overview
Cards: Active Members, MRR, Average Ticket, New Members, Cancellations, Cancellation Rate, Delinquency Rate, Visits per Member.
Visuals: MRR evolution, member growth, MRR by unit, members by plan, acquisition-channel performance.

## Page 2 — Retention & Customer Analytics
Visuals: cancellation by plan/unit, average tenure, acquisition quality, cohort/retention matrix and tenure distribution.

## Page 3 — Usage & Operations
Visuals: visits by unit, weekday and time slot, activity popularity, unique visitors, visits/member and capacity-demand heatmap.

## Visual Direction
Use a dark navy base, teal for primary KPIs and purple for retention/customer analytics. Avoid funnel visuals so this project has a different visual language from the sales-funnel case.
